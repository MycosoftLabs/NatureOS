# NatureOS Simulink Models

Simulink models for environmental control, irrigation, lighting, and alert systems.
Requires MATLAB R2024a+ with Simulink.

## Models

| Model | Purpose |
|-------|---------|
| `environmentalControl.slx` | Temperature/humidity control loops |
| `irrigationSystem.slx` | Smart irrigation control |
| `lightingControl.slx` | Growth chamber lighting |
| `alertSystem.slx` | Multi-sensor alert logic |

## Creating Models

Run `createModels.m` in MATLAB to generate the .slx files from specifications.
